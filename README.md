# Receita - Cupcake de Café

Uma página web elegante com a receita de **Cupcake de Café com Chantilly**.

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização e layout
- **Google Fonts** - Tipografia (Alice)

## 🚀 Como Visualizar

### Online

Acesse a versão online em: **[https://kiovaz.github.io/receita_cupcake](https://kiovaz.github.io/receita_cupcake)** 🔗

### Localmente
1. Clone o repositório:
```bash
git clone https://github.com/kiovaz/receita-cupcake.git
```

2. Navegue até a pasta do projeto:
```bash
cd receita-cupcake
```

3. Abra o arquivo `index.html` no seu navegador preferido
